**Goal:** Make incoming calls reach real two-way audio and reliably dismiss on reject, hangup, expiry and remote termination.

**Architecture:** Keep `VoiceCallManager` as the lifecycle coordinator, `VoiceCallSignalRService` for signaling, `VoiceWebRtcService` for media, and the existing ViewModel/screens for UI. The server snapshot controls terminal and Active states; local peer events trigger media reports but cannot by themselves start the call timer.

**Tech stack:** Flutter, flutter_bloc, Dio/Retrofit, SignalR, flutter_webrtc, flutter_callkit_incoming.

## Findings to verify during implementation

- `voice_call_signalr_service.dart` already registers `call:event`, `rtc:offer`, `rtc:answer` and `rtc:ice-candidate`, then calls `BindDeviceSession(deviceSessionId, controlProof)` and rebinds after reconnection. Verify the exact deployed hub payload and event sequence before rewriting this flow.
- `voice_call_manager.dart` sends `/reports/connecting` after answer and ICE initialization, even before an offer/peer connecting state. It sends `/reports/connected` on peer connected but also starts the timer from `DateTime.now()` before checking the report or receiving an authoritative Active snapshot.
- `voice_call_manager.dart` closes CallKit before checking the result of `/reject` or `/end`, then cleans up. `calling_view_model.dart` emits Rejected/Ended even if the manager did not confirm server success. Native End while still Ringing also goes to `/end`, which the backend disallows.
- Incoming CallKit uses a fixed 30-second duration, while the snapshot can have a different `deadlineAtUtc`; `snapshot.isExpired` only acts when a snapshot is applied. A scheduled deadline reconciliation is needed for an otherwise quiet ringing call.

**Acceptance:** The user app shows Active/duration only after server confirmation, rejects or ends with the correct API action, clears incoming/active native UI on terminal or deadline reconciliation, and carries audible media both ways on real networks. Local tests do not establish deployed TURN readiness.
