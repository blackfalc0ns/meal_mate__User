# Project Instructions

Before making any changes in this project, you MUST read and follow the relevant rules.

## UI / Design Tasks

For any UI, Figma, widget, screen, styling, theme, localization, spacing, or layout work, read and follow:

`rules/ui_rules.md`

## Backend / API Integration Tasks

For any API integration, backend connection, DTO, Entity, Mapper, Repository, UseCase, DataSource, Cubit/ViewModel, Event, State, Retrofit, Dio, or dependency injection work, read and follow:

`rules/backend_rules.md`

## Mixed Tasks

If a task involves both UI and backend integration, you MUST read and follow both files:

- `rules/ui_rules.md`
- `rules/backend_rules.md`

## Important

- Existing project architecture has priority.
- Do not create a new architecture without checking the existing code first.
- Do not modify unrelated files.
- Reuse existing code before creating new code.
